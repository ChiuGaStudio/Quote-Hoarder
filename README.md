# Quote Hoarder website

Static bilingual product, support, and privacy website for 隨拾句（Quote Hoarder）.

## Pages

- `/` — product page
- `/support/` — support and contact page
- `/privacy/` — privacy policy

No build step or external dependency is required. Serve the directory with any static web server.

Before launch, replace the “coming soon” message with the real App Store link and use the deployed `/support/` and `/privacy/` URLs in App Store Connect.
